A manual Maven repository for Serilum's Minecraft mods and libraries.

Add the repository

Add the repository to each loader's build.gradle:

repositories {
	maven { url "https://maven.serilum.com/" }
}

Dependencies

Pull in the active Collective library. It ships an artifact per loader plus a shared collective-common, matching the multiloader build.gradle layout:

Common

dependencies {
	compileOnly "com.natamus.collective-ml:collective-common:VERSION"
}

Fabric

dependencies {
	implementation "com.natamus.collective-ml:collective-fabric:VERSION"
}

Forge

dependencies {
	implementation "com.natamus.collective-ml:collective-forge:VERSION"
}

NeoForge

dependencies {
	implementation "com.natamus.collective-ml:collective-neoforge:VERSION"
}

Replace VERSION with <minecraft>-<collective> (the current latest is latest), then pick the one matching your Minecraft version from the list below. The older github.com/Serilum/.maven/raw/maven/ URL keeps working too.
